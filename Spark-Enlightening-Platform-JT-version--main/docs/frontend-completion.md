## 交付与使用

在项目根目录执行 `node tools/preview.cjs`，打开 `http://127.0.0.1:4173/`。

`dist/ai-science-site.zip` 只包含五个静态页面与站点assets，不包含开发依赖、截图、迁移脚本和原始大文件。尚未部署时可直接解压预览；上线后请用真实站点根网址重新打包：

```powershell
python tools/package_site.py --base-url https://你的真实域名/站点子目录/
```

把URL换成真实地址，不保留示例字面值。主机按平台方式启用404页，然后在微信/QQ中验证真实链接。此脚本生成文件，不会自动上传或发布。

本机学习昵称、头像仍只保存在浏览器。原先的静态“登录”不进行任何身份认证，已明确改为本机学习档案且不再收集无用途的密码；随堂助手标注为预设回复演示，没有冒充已接通真实AI服务。

原始页面位于项目同级的 `_original_pages_before_optimization/`，原始媒体位于 `_original_media_before_optimization/`。原目录 `_backup_before_fix/`未改动。
